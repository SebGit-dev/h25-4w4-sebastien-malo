# Examen Final Page Web Voyage

## Concevoir un site Wordpress pour un club de voyage

### Auteur: Sebastien Malo

La réalisation de ce thème permettra d'optimiser la présentation d'un contenu spécifique sur différentes destination de voyages. Ajouter la page pays avec des champs personnalisés pour annoncer la date, heure, conférencier et les coordonnées  du  prochain événement.
